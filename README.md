# Junior Style Hub

Prompt for Lovable AI

Create a modern, premium, and fully responsive online boys' fashion shopping website. The website should focus on clothing and fashion products for boys and young men.

Design & Theme

Use a clean white theme as the main background.

Create a modern, minimal, elegant, and premium look.

Use black and dark gray text for contrast.

Add subtle shadows, rounded corners, smooth animations, and hover effects.

Use high-quality fashion images.

Make the design attractive and easy to navigate.

Pages & Features

1. Home Page

Include:

A modern hero banner featuring boys' fashion.

A clear Shop Now call-to-action button.

Featured collections.

New arrivals.

Trending styles.

Best-selling products.

Special offers and discounts.

2. Navigation Bar

Include:

Brand logo

Home

Shop

New Arrivals

Categories

Offers

Search

Wishlist

Shopping Cart

User Account

3. Product Categories

Create categories such as:

T-Shirts

Shirts

Hoodies

Jackets

Jeans

Trousers

Shorts

Ethnic Wear

Casual Wear

Formal Wear

Party Wear

4. Product Cards

Each product card should include:

High-quality product image

Product name

Brand name

Price

Original price and discount percentage

Star rating

Available sizes

Wishlist icon

Add to Cart button

Quick View option

5. Product Details Page

Include:

Multiple product images with image gallery.

Product name and brand.

Price and discount.

Size selection.

Color selection.

Quantity selector.

Add to Cart button.

Add to Wishlist button.

Product description.

Delivery information.

Customer reviews.

Related products.

6. Shopping Cart

Include:

Selected product details.

Product image and name.

Size and quantity.

Increase/decrease quantity buttons.

Remove item option.

Subtotal.

Discount.

Delivery charge.

Final total.

Proceed to Checkout button.

7. Search & Filters

Allow users to:

Search for products.

Filter by category.

Filter by size.

Filter by color.

Filter by price range.

Filter by brand.

Sort by newest, popularity, price low-to-high, and price high-to-low.

8. Wishlist

Allow users to:

Add products to wishlist.

Remove products from wishlist.

Move wishlist products to the shopping cart.

9. Checkout

Include:

Customer information form.

Shipping address.

Order summary.

Payment method selection.

Place Order button.

Order confirmation page.

Technical Requirements

Build a fully responsive website for mobile, tablet, and desktop.

Use reusable and well-structured components.

Ensure smooth navigation between pages.

Add subtle animations and transitions.

Use realistic sample products and data.

Include proper form validation.

Make all buttons and interactions functional.

Do not leave empty pages, broken links, or placeholder functionality.

Quality Check

Before finalizing:

Verify all navigation links and pages work correctly.

Test search, filtering, sorting, wishlist, and cart functionality.

Check product quantity and price calculations.

Ensure the website is responsive on mobile, tablet, and desktop.

Maintain a consistent white, clean, and premium theme.

Check for UI alignment, spelling mistakes, broken buttons, and errors.

Final Instruction

Create a professional, stylish, premium online boys' clothing shopping website with a clean white theme, modern UI/UX, realistic fashion product layouts, smooth animations, and fully functional shopping features. The final result should feel like a real-world e-commerce fashion platform.
